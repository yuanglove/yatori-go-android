# v0.4.0 Android repair and APK packaging update

- Forward upstream Go progress logs into Android log panels and task summaries.
- Restore bounded scrolling on older WebView versions without `dvh` support.
- Preserve course-state filtering and avoid orphaned requests from artificial timeout wrappers.
- Recreate the generated APK before packaging to avoid unused ZIP space when replacing libgojni.so.

Version remains 0.4.0 (versionCode 40). Existing app data is retained on compatible in-place installation.

## Build provenance

The tested APK was built from desktop base 1ea2343 plus the repairs now published in desktop commit 821b6557a909064f864d4e7aae9b230d8d1472eb. Its embedded coreCommit records the base commit because the repairs were uncommitted when built. The AAR checksum identifies the actual patched core; do not interpret the embedded base commit as an unmodified upstream build.
